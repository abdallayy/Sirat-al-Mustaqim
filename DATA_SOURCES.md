# Data sources and attribution

## Quran

- Uthmani Arabic Quran dataset retrieved from [AlQuran Cloud](https://alquran.cloud/) (`quran-uthmani` edition), sourced from the [Tanzil Project](https://tanzil.net).
- Copyright: Tanzil Quran Text, Copyright (C) 2007-2021 Tanzil Project. License: [Creative Commons Attribution 3.0](https://tanzil.net/docs/Text_License).
- The text is distributed verbatim and must not be changed. The copyright notice and source attribution are included in `public/data/quran.json`; the app links to Tanzil from the Quran reader.
- The fetch script fails unless the source returns exactly 114 surahs and 6,236 ayahs.

## Hadith

- Arabic editions `ara-bukhari` and `ara-muslim` from [fawazahmed0/hadith-api](https://github.com/fawazahmed0/hadith-api), delivered through jsDelivr. The upstream repository is released under the [Unlicense](https://github.com/fawazahmed0/hadith-api/blob/1/LICENSE).
- The app labels each narration by its source collection and source-provided hadith number. Numbering can differ between print editions.
- Source records without Arabic text are omitted and counted in the fetch command output. No English translation or authenticity grade beyond the named canonical collection is generated by this app.

## Tafsir

- Per-ayah Tafsir al-Muyassar is requested on demand from the AlQuran Cloud API (`ar.muyassar`) and is not included in the repository or stored offline.
- The reader credits AlQuran Cloud for each response. Confirm the provider's current API and tafsir reuse terms before distributing a public or commercial deployment.

## Quran recitation audio

- Ayah audio is streamed from the Islamic Network CDN through AlQuran Cloud's audio-edition identifiers: Alafasy, Abdurrahmaan As-Sudais, Husary, Minshawi, Maher Al Muaiqly, and Hudhaify. The app uses each edition's published bitrate (192 kbps for As-Sudais; 128 kbps for the others).
- Audio is streamed on demand and is not bundled or cached for offline playback. Check the upstream service's current terms before public distribution.

## Scope and limitations

The app also provides locally calculated prayer times, Qibla direction, reading and dhikr progress, Hijri date display, and an offline app shell. Prayer times are estimates; calendar dates and compass readings depend on the device and local authorities.

Remote tafsir and audio require internet access. Offline availability depends on which datasets have previously loaded and on browser storage quota. Notification delivery while the browser is closed requires a separately configured Push server.
